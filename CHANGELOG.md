# Changelog

## 2.0.0

Update the pinned Crawlora SDK to `1.49.0-sdk.4` and remove the retired Google Search tool from the starter and Google platform package. The starter now exposes 22 tools, and the 202 platform packages expose 213 distinct tools. Refresh Amazon Jobs, Shopify, Rotten Tomatoes, and Threads package schemas from the current SDK metadata. Google retired its upstream search endpoint on 2026-10-20.

## 1.0.0

Initial standalone native OpenClaw release with 23 Crawlora tools, pinned host compatibility, request-contract tests, cancellation, safe errors, and packaged installation validation.
